# Screenshot provenance

`controls-sample.png` was rendered on 25 September 2026 using Quickshell's
offscreen Qt renderer. It uses the production `Panel.qml` content column,
`SignalIcon.qml`, and installed Omarchy UI components and theme. A standalone
host supplies fictional modem state instead of executing the production
backend. The image is captured with Qt's `grabToImage`, not generated by AI.

The panel's normal logical width and theme padding are retained; output is
rendered at double resolution. The sample labels are visible in the image.
The address 192.0.2.10 is a documentation example. Signal strength, traffic,
profile, carrier and connection state are illustrative, not measurements.

There was no modem available to capture live on the screenshot machine.

This capture predates the Modem Manager rename and retains the earlier panel
heading. The current promotional composite uses the new name.
